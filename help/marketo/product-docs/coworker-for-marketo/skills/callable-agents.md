# 可呼叫的代理程式 {#callable-agents}

可呼叫的代理程式可讓您將AI代理程式用作Marketo Engage Smart Campaign中的步驟。 在Marketo Engage的CX Enterprise Coworker中建立代理程式，選擇讀取和更新的潛在客戶欄位，並發佈以用於行銷活動。 代理程式有助於清理資料、分類銷售機會、豐富遺漏的資訊，或熒幕表單提交。

>[!PREREQUISITES]
>
>您必須在Marketo Engage中擁有&#x200B;**存取管理員**&#x200B;許可權。

## 開始之前 {#before-you-begin}

- 決定代理程式需要讀取哪些潛在客戶欄位以及它應該更新哪些欄位。 每個輸入和輸出都必須對應至Marketo Engage銷售機會欄位。
- 確認輸出欄位是可更新的。 不支援唯讀欄位和方案成員欄位。

## 使用方式 {#how-to-use}

1. 在「我的Marketo」中，按一下「**[!UICONTROL CX Enterprise Coworker for Marketo Engage]**」圖磚。

1. 在左側導覽中選取&#x200B;**[!UICONTROL Callable agents]**。 清單會顯示每個代理程式的名稱、建立日期、建立者和狀態。 依名稱搜尋，或依名稱或建立日期排序。

1. 選取「**[!UICONTROL Create callable agent]**」。 選擇範本，或讓範本選擇器保持空白以從頭開始。

1. 輸入&#x200B;**[!UICONTROL Agent name]**&#x200B;並寫入&#x200B;**[!UICONTROL Agent instructions]**，說明如何處理每個銷售機會。

1. 在&#x200B;**[!UICONTROL Lead fields to send]**&#x200B;底下，新增代理程式需要的潛在客戶欄位作為輸入。 在&#x200B;**[!UICONTROL Lead fields to update]**&#x200B;底下，新增代理程式應傳回的每個值，並將其對應至可更新的潛在客戶欄位。

1. 選取&#x200B;**[!UICONTROL Save]**&#x200B;以儲存草稿，或選取&#x200B;**[!UICONTROL Save and publish]**&#x200B;讓代理程式可在Marketo Engage中使用。

1. 開啟Smart Campaign並選取&#x200B;**[!UICONTROL Flow]**&#x200B;標籤。 在流程步驟清單的行銷區段中，尋找&#x200B;**通話代理程式： _[代理程式名稱]_**，並將其拖曳至流程中。

1. 使用一小部分潛在客戶集測試行銷活動。 檢閱活動記錄並確認輸出欄位會如預期更新，然後再為所有潛在客戶啟用行銷活動。

## 注意事項 {#things-to-note}

- 可呼叫的代理程式會獨立處理每個銷售機會。 Marketo Engage會將對應的銷售機會值傳送至代理程式，將傳回的值寫入對應的銷售機會欄位，然後繼續下一個促銷活動步驟。
- 您可以在適用於Marketo Engage的CX Enterprise Coworker中建立和管理可呼叫的代理程式。 不需要外部連線。
- 無法編輯已發佈的代理程式。 若要變更已發佈的代理程式，您必須建立新的代理程式並更新相關的Smart Campaigns。

## 建立代理程式 {#create-an-agent}

### 從頭開始建立代理程式 {#create-an-agent-from-scratch}

讓範本選擇器保持空白。 表單從一個空白輸入欄位和一個空白輸出欄位開始。 輸入名稱和指示，然後設定輸入和輸出欄位以符合您的商業規則。

### 從範本開始 {#start-from-a-template}

選擇範本以預先填寫指示、輸入欄位和輸出欄位。 代理程式會儲存為您自己的復本，您可編輯或刪除。 如果您刪除從範本建立的代理程式，則範本會再次出現在選擇器中。

| 範本 | 用途 | 輸入 | 輸出 |
| --- | --- | --- | --- |
| 公司名稱標準化程式 | 移除合法尾碼、更正常見拼寫錯誤並套用標準品牌大寫格式，以清除公司名稱。 | 公司 | 標準化公司（文字）；信賴度（數字） |
| 電話E.164格式化程式 | 將電話號碼格式設定為國際E.164標準。 | 電話 | 標準化電話（文字）；信賴度（數字） |
| 職稱標準器 | 將職稱標準化，並取得資歷。 | 職稱 | 標準化的標題（文字）；資歷（C級、VP、主管、經理、個人或未知）；信賴 |
| 機器人和垃圾郵件偵測器 | 標籤機器人或垃圾郵件表單提交。 | 電子郵件、名字、姓氏、公司、電話 | 是機器人(true/false)；信賴；原因；旗標（逗號分隔） |
| 可處置的電子郵件偵測器 | 識別暫時或可處置的電子郵件地址。 | 電子郵件 | 是機器人(true/false)；可信度；原因；電子郵件型別（可丟棄、個人或企業） |
| 潛在客戶分類器 | 依公司規模、產業、角色和意圖劃分的區段有領先優勢。 | 公司、職稱、電子郵件、員工、收入 | 區段（企業、中端市場、中小型企業、初創公司或未知）；產業；角色；意圖層級（高、Medium或低）；可信度 |
| 潛在客戶擴充 | 推斷現有資訊中缺少潛在客戶詳細資訊。 | 電子郵件、標題、公司 | 推斷的公司、部門、資歷、是決策者（真/假）、是B2B （真/假）、信賴度 |
| 公司研究 | 從公司資訊產生銷售情報。 | 公司、網站、說明 | 如需完整清單，請參閱範本 |

### 撰寫有效指示 {#write-effective-instructions}

- 在代理程式指示中放入一般規則和範例。 使用欄位指示來指定個別輸出的期望。
- 請具體說明。 例如，「移除Inc、LLC和Corp等合法尾碼」比「清理公司名稱」更清楚。
- 包含輸入和預期輸出的範例，尤其是邊緣情況。
- 說明代理程式在無法決定時應傳回的內容，例如「如果您不確定，請傳回原始值」。
- 新增可信度輸出，讓行銷活動邏輯可路由低可信度結果以供檢閱。
- 保持提示簡潔。 較短的提示執行速度更快，成本更低。

## 儲存、發佈和管理代理程式 {#save-publish-and-manage-agents}

### 另存為草稿或發佈 {#save-as-a-draft-or-publish}

選取&#x200B;**[!UICONTROL Save]**&#x200B;將代理程式儲存為草稿。 草稿可以編輯，但無法作為Smart Campaign流程步驟使用。 當代理程式準備就緒時，選取&#x200B;**[!UICONTROL Save and publish]**。 Marketo Engage會提供代理程式作為流程步驟，並在確認發佈後傳回代理程式清單。 選取&#x200B;**[!UICONTROL Cancel]**&#x200B;以離開而不儲存。

| 狀態 | 含義 | 可用動作 |
| --- | --- | --- |
| 草稿 | 代理程式已儲存，但在Marketo Engage中無法使用。 | 編輯它，然後在準備就緒時選取&#x200B;**[!UICONTROL Save and publish]**。 |
| 發佈日期 | 此代理程式適用於Smart Campaigns。 已發佈的代理程式已凍結。 | 使用已發佈的代理程式，或建立新的代理程式以進行變更。 |
| 發佈失敗 | 例如，Marketo Engage已拒絕代理程式，因為已保留輸出欄位名稱。 但代理程式仍會儲存為草稿。 | 編輯代理程式，更正訊息中名為的欄位，然後再次發佈。 |

### 編輯、檢查使用情況或刪除 {#edit-check-usage-or-delete}

- 在草稿上選取&#x200B;**[!UICONTROL Edit]**&#x200B;以變更。 **[!UICONTROL Save]**&#x200B;讓您停留在頁面上，並顯示「代理程式已儲存」確認。 您也可以選取&#x200B;**[!UICONTROL Save and publish]**、**[!UICONTROL Cancel]**&#x200B;或&#x200B;**[!UICONTROL Delete]**。
- 已發佈的代理程式已凍結，因為Smart Campaigns可能取決於它們。 建立新代理以進行變更。
- 在刪除代理程式或變更其行銷活動設定之前，請檢查&#x200B;**[!UICONTROL Used by]**&#x200B;以檢視哪些Smart Campaigns參考代理程式。
- 當Smart Campaign仍使用代理程式時，您無法刪除代理程式。 從每個列出的行銷活動中移除代理程式的流程步驟，然後刪除代理程式。

## 組織規則整合 {#organizational-rules-integration}

### 命名慣例 {#naming-conventions}

- **代理程式名稱：** 1-100個字元，且在訂閱內是唯一的。 此名稱也會用於智慧型行銷活動流程步驟中。 選擇可辨識的名稱，例如`Company Name Normalizer`。
- **輸出欄位名稱：**&#x200B;使用字母、數字和底線。 名稱必須以字母或底線開頭、必須是唯一的，並且不能超過64個字元。
- **保留名稱：**&#x200B;某些輸出名稱保留供系統使用。 如果名稱被拒絕，請選擇其他名稱，例如`qualificationReason`而不是`reason`。

### 必要元素和支援的欄位 {#required-elements-and-supported-fields}

- 儲存之前，將每個輸入欄位對應至Marketo Engage銷售機會欄位。
- 設定至少一個輸出欄位。 將每個輸出對應到可更新的潛在客戶欄位；唯讀欄位在欄位選擇器中不可用。
- 不支援程式成員欄位。 欄位選擇器僅顯示潛在客戶欄位。
- 支援的輸出型別為&#x200B;**Text**、**Number**&#x200B;和&#x200B;**True/False**。
- 若要傳回清單，請使用逗號分隔文字值，並在欄位指示中說明預期的格式。
- 每次成功執行都會完全傳回已設定的輸出欄位。

### 限制 {#limits}

| 設定 | 限制 |
| --- | --- |
| 專員名稱 | 1至100個字元；在訂閱內不重複 |
| 代理程式指示 | 1-4,000個字元 |
| 輸入欄位 | 最多20個；每個都必須對應至潛在客戶欄位 |
| 輸出欄位 | 1-20；每個都必須對應至可更新的潛在客戶欄位 |
| 輸出欄位名稱 | 最多64個字元；字母、數字和底線；以字母或底線開頭；唯一 |
| 輸出欄位指示 | 最多512個字元 |
| 每個請求的潛在客戶 | 來自Marketo Engage最多1,000個銷售機會，以並行方式處理 |

## 內容篩選和資料處理 {#content-screening-and-data-handling}

當您建立代理程式或編輯其指示時，Marketo Engage會針對原則違規、提示插入和資料匯出嘗試，篩選代理程式指示和輸出欄位指示。 例如，要求顯示認證或覆寫代理程式行為。 如果內容被標幟，儲存會被封鎖並會顯示訊息，例如「提示包含受限制內容」或「提示失敗的內容稽核」。 修訂文字並再次儲存。

- **存取：**&#x200B;管理代理程式需要&#x200B;**存取管理員**&#x200B;許可權。 代理程式和通話記錄會由訂閱隔離。
- **潛在客戶資料保護：**&#x200B;潛在客戶資料與代理程式指示分開傳遞，其保護措施將潛在客戶值視為資料而非命令。
- **內容原則：**&#x200B;如果潛在客戶的資料違反AI提供者的內容原則，該潛在客戶會收到錯誤活動，而非結果。
- **保留：**&#x200B;要求與回應裝載（包括傳送給代理程式的潛在客戶欄位值）會在通話記錄中保留30天以支援疑難排解，然後自動刪除。

## 可呼叫代理程式在行銷活動中的執行方式 {#how-callable-agents-run-in-a-campaign}

1. 當行銷活動執行時，Marketo Engage會將每個合格銷售機會的對應銷售機會欄位值傳送給代理。
1. 代理程式會獨立處理每個銷售機會，並傳回已設定的輸出欄位。
1. Marketo Engage會將結果寫入對應的潛在客戶欄位。 變更的欄位也會顯示為標準資料值變更活動。
1. 行銷活動會移至下一個步驟。

處理為非同步。 流程步驟會等待結果，一直到Marketo Engage中的流程步驟等待視窗。 如果一個銷售機會失敗（例如，由於逾時），該銷售機會會收到錯誤活動，而其他銷售機會會繼續。 每個結果都會顯示在潛在客戶可呼叫代理程式的活動記錄中。

在行銷活動邏輯中使用輸出欄位。 例如，**上的分支是機器人**，以不同方式路由垃圾訊息提交，或是&#x200B;**信賴度**&#x200B;上的分支，以傳送低信賴度結果給檢閱步驟。

## 預先啟用QA {#pre-activation-qa}

為所有潛在客戶啟用行銷活動之前：

- 使用小型潛在客戶測試集執行行銷活動。
- 檢閱每個潛在客戶的活動記錄，並確認輸出欄位已正確更新。
- 測試邊緣案例，包括遺漏值和異常輸入。
- 確認行銷活動分支會如預期處理低信賴度或機器人/垃圾郵件分類之類的值。

## 使用案例 {#use-cases}

- **資料清理：**&#x200B;在建立或匯入潛在客戶時，將公司名稱標準化、將電話號碼格式化為E.164，並將職稱標準化。
- **機器人和垃圾郵件篩選：**&#x200B;檢查提交的垃圾名稱、可疑電子郵件和重複數字的電話號碼；根據結果分支行銷活動。
- **可丟棄電子郵件偵測：**&#x200B;識別暫存電子郵件地址，並將其路由方式與公司地址不同。
- **銷售機會分類：**&#x200B;依公司規模、產業、角色以及支援路由或評分的意圖劃分的銷售機會。
- **潛在客戶擴充：**&#x200B;推斷缺少的詳細資訊，例如，部門、資歷，或潛在客戶是否為決策者。
- **自訂規則：**&#x200B;建立可描述為潛在客戶處理規則的是/否檢查或分類，例如標幟來自地區或行業的潛在客戶。

## 疑難排解 {#troubleshooting}

| 問題 | 解決方法 |
| --- | --- |
| **代理程式**&#x200B;未出現在導覽中。 | 請要求您的Marketo Engage管理員授予&#x200B;**存取管理員**&#x200B;許可權。 |
| 儲存被內容訊息封鎖。 | 修訂代理程式指示或欄位指示以移除標籤的內容，然後再次儲存。 |
| 代理程式狀態為&#x200B;**發佈失敗**。 | 編輯代理程式，更正訊息中命名的欄位，然後選取&#x200B;**儲存並發佈**。 |
| 您無法編輯已發佈的代理程式。 | 已發佈的代理程式已凍結。 建立新代理以進行變更。 |
| 您無法刪除代理程式。 | 使用代理程式從每個列出的Smart Campaign中移除其流程步驟，然後刪除它。 |
| 欄位名稱會回報為保留。 | 選擇不同的輸出欄位名稱，例如`qualificationReason`，然後再次儲存。 |
| 有些潛在客戶會收到錯誤活動。 | 檢查潛在客戶的活動記錄。 個別的失敗（包括逾時或內容原則違規）不會影響其他銷售機會。 |
| 結果不是預期的。 | 讓指示更具體化、新增範例、調整欄位指示，然後使用一小部分潛在客戶再次測試。 |

## 後續步驟 {#next-steps}

- 檢閱代理程式的&#x200B;**使用者**&#x200B;清單，並確認哪些Smart Campaigns將使用它。
- 使用一小群潛在客戶測試流程步驟，並驗證活動記錄和輸出欄位。
- 使用輸出欄位，為分類或低信賴度結果新增行銷活動分支。
- 刪除代理之前，請從所有行銷活動移除代理程式流程步驟。
